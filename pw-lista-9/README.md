# 🚀 Atividades Práticas: HTML & CSS (Grid, Flexbox e Position)

Bem-vindo ao repositório de atividades práticas! Este espaço reúne dois desafios projetados para consolidar o domínio de estruturação e estilização de layouts web utilizando **HTML e CSS puros**, sem o uso de frameworks.

As atividades estão divididas em pastas específicas dentro deste repositório. Confira os detalhes de cada uma abaixo:

---

## 📂 Estrutura do Repositório

```text
├── 🧩 calculadora/
│   ├── index.html
│   ├── style.css
│   └── README.md (Instruções específicas da Calculadora)
│
└── 💻 land-page/
    ├── assets/ (Imagens de suporte: banner.png e logo.png)
    ├── index.html
    ├── style.css
    └── README.md (Instruções específicas da Landing Page)

```

---

## 🧩 1. Desafio: Clone de Calculadora com CSS Grid

Localizado na pasta `/calculadora`, o objetivo deste desafio é reproduzir o visual de uma calculadora real, focando na organização geométrica dos botões e do visor.

* **🎯 O Desafio:** Escolher uma calculadora real (física ou virtual) e reproduzir seu design.
* **🛠️ Foco Técnico:** Aplicação prática de `display: grid`.
* **📸 Requisitos de Entrega:**
* Foto/Print da calculadora original escolhida para comparação.
* Print da versão final desenvolvida por você.
* Código estruturado em `index.html` e `style.css`.

---

## 💻 2. Atividade: Clone de Layout (Landing Page)

Localizado na pasta `/land-page`, esta atividade exige um nível maior de fidelidade visual, combinando diferentes técnicas de alinhamento para criar uma página estática moderna.

* **🎯 O Desafio:** Reproduzir fielmente o protótipo de interface fornecido na pasta de recursos.
* **🛠️ Foco Técnico:** Uso estratégico combinado de `Grid Layout`, `Flexbox` e `Position` (relative/absolute).
* **🚫 Regra Importante:** É estritamente proibido o uso de frameworks (como Bootstrap ou Tailwind). Tudo deve ser feito de forma manual e pura.
* **📦 Recursos Disponíveis:** Dentro da pasta `assets/`, você encontrará o modelo de referência, além dos arquivos `banner.png` e `logo.png` para utilizar no projeto.

---

## 📝 Orientações Gerais para o Desenvolvimento

1. **Organização:** Certifique-se de trabalhar dentro da pasta correta de cada atividade para não misturar os códigos.
2. **Atenção aos Detalhes:** Observe atentamente os alinhamentos, espaçamentos, proporções e fontes. O objetivo é demonstrar domínio técnico e sensibilidade visual.
3. **Boas Práticas:** Código limpo e bem identado. Comentários explicando a lógica do CSS são sempre bem-vindos!
